# Книжный клуб — подборщик следующей книги

Веб-приложение для книжного клуба: участники предлагают книги, голосуют один раз и сразу видят, что читать следующим. Без длинных обсуждений в чате.

## Как запустить

**Вариант 1 — просто открыть файл:** двойной клик по `index.html`.

**Вариант 2 — локальный сервер** (нужен, если браузер ограничивает `file://`):

```bash
python -m http.server 8765
```

и открыть http://localhost:8765

Сборка не требуется: чистые HTML/CSS/JS, без фреймворков и зависимостей.

## Возможности

- **Каталог кандидатов** — обложка-заглушка, автор, жанр, число страниц, кто предложил.
- **Фильтры** — по жанру и объёму (до 300 / 301–500 / больше 500 страниц), кнопка «Сбросить фильтры».
- **Форма «Предложить книгу»** — добавление в каталог, нельзя добавить книгу без названия.
- **Голосование** — правило «один участник — один голос»; повторный голос невозможен, смена голоса — только с подтверждением.
- **Рейтинг** — обновляется сразу после голоса: место, число голосов, доля, лидеры.
- **Регистрация и вход** — логин и пароль (хеш SHA-256), сессия в браузере.
- **Мой профиль** — отображаемое имя (меняется в рейтинге и комментариях, включая прошлые записи) и смена пароля.
- **Комментарии** — отзывы к книгам после чтения; свои можно удалить.
- **Мои результаты** — панель: ваш голос и все ваши комментарии.
- **Главный экран** — сброс фильтров и возврат наверх.

## Правило «один участник — один голос»

- Ключ участника — нормализованный логин (`trim` + lowercase + схлопывание пробелов): «Женя», «женя » — один участник.
- Голос пишет только одна функция `castVote()`: она перечитывает хранилище, проверяет, нет ли уже голоса у этого ключа, и затем пишет — проверка и запись в одном месте.
- На время записи кнопки блокируются (защита от двойного клика).
- Смена голоса возможна, но только через явное подтверждение — итог всё равно один голос на участника.

## Данные

Всё хранится в `localStorage` браузера (демо-режим, голосуют на одном устройстве):

| Ключ | Что хранит |
|---|---|
| `bc_books_v1` | каталог книг |
| `bc_votes_v1` | голоса: `{bookId, voterKey, voterName, ts}` |
| `bc_comments_v1` | комментарии к книгам |
| `bc_users_v1` | участники: логин, имя, хеш пароля |
| `bc_session_v1` | текущий вход |

При первом запуске подгружаются демонстрационные книги, голоса и комментарии. Кнопка «Очистить каталог» удаляет их и показывает пустое состояние.

## Технологии

- HTML / CSS / JavaScript (ES2020+), без сборки и зависимостей;
- `localStorage` для хранения;
- Web Crypto API (SHA-256) для хеша пароля с запасным вариантом, если API недоступен.

Если клуб переходит на голосование с разных устройств, хранение нужно заменить на серверное (в ТЗ рекомендован Python + Streamlit + SQLite) — логика голосования и нормализация имени при этом переносятся как есть.

## Структура

```
index.html   — разметка: шапка, каталог, формы, рейтинг, модалка профиля

app.js       — состояние, хранилище, правила голосования, комментарии, отрисовка
AGENTS.md    — техническое задание и чек-лист проекта
```

## Критерии готовности

- [x] Один участник голосует только один раз.
- [x] Рейтинг пересчитывается сразу после голоса.
- [x] Фильтр по жанру работает и сбрасывается.
- [x] Пустой каталог показывает подсказку «Предложите первую книгу».
- [x] Нельзя добавить книгу без названия.
